# Review Marks

Marking up text in a note during review: highlighting passages and attaching comments for whoever revises the note next.

## Language

**Annotation**:
A Target paired with one Comment, recorded in the note itself.
_Avoid_: Mark, note, markup (for a single item)

**Target**:
The span of note text an Annotation points at; shown highlighted.
_Avoid_: Anchor, selection, range

**Comment**:
The free-text message attached to a Target, read by whoever revises the note.
_Avoid_: Instruction, note, action

**Reviewer**:
The person who creates and edits Annotations while reading a note.
_Avoid_: User, annotator

**Resolution**:
Acting on an Annotation's Comment and removing the Annotation from the note; done by whoever revises the note, outside the plugin.
_Avoid_: Reconciliation, fix, apply
