# Review Markup

Marking up text in a note during review: highlighting passages and attaching instructions for whoever revises the note next.

## Language

**Annotation**:
A Target paired with one Instruction, recorded in the note itself.
_Avoid_: Comment, note, markup (for a single item)

**Target**:
The span of note text an Annotation points at; shown highlighted.
_Avoid_: Anchor, selection, range

**Instruction**:
The free-text message attached to a Target, telling the reviser what to do with it.
_Avoid_: Comment, note, action

**Reviewer**:
The person who creates and edits Annotations while reading a note.
_Avoid_: User, annotator

**Resolution**:
Acting on an Annotation's Instruction and removing the Annotation from the note; done by whoever revises the note, outside the plugin.
_Avoid_: Reconciliation, fix, apply
